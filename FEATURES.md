# Machine Learning Feature Dictionary - Spotify Age Predictor

This document provides a comprehensive specification of every feature in the machine learning dataset generated by this application.

The target variable for machine learning classification/regression is **`age_group`**. All other features are strictly derived from automated Spotify Web API calls or demographic metadata.

---

## Target Variable

| Feature Name | Data Type | Description | Values / Range | Missing Value Behavior |
| :--- | :--- | :--- | :--- | :--- |
| `age_group` | Categorical String | Target demographic age group cohort selected by respondent | `'Under 18'`, `'18-24'`, `'25-34'`, `'35-44'`, `'45-54'`, `'55+'` | Required field |

## Excluded Features & Spotify 2026 API Restrictions

The following legacy features were explicitly **excluded** from collection to comply with Spotify Web API rules:

1. **Audio Features Endpoint (`/audio-features`)**: `danceability`, `energy`, `valence`, `acousticness`, `instrumentalness`, `speechiness`, `tempo`, `loudness`, `key`, `mode` were deprecated by Spotify.
2. **Audio Analysis Endpoint (`/audio-analysis`)**: Excluded.
3. **Track & Artist Popularity Metrics**: Popularity integer scores were removed/unreliable in current Spotify endpoints.
4. **Exact User Age & Exact Birthday**: Spotify API does not expose exact age or date of birth. Demographics are voluntarily gathered via broad age group cohorts (`Under 18`, `18-24`, `25-34`, `35-44`, `45-54`, `55+`).
